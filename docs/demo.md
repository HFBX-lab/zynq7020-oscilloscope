# 演示步骤

这些步骤适用于已正确组装、运行实板验证版本的仪器。模块、板卡和输入电压须符合实际原理图及 ADC 输入范围。

1. 保持板卡 QSPI 启动拨码（本项目使用的板卡为 S1 白、S2 黑），断电再只上电，等待自动进入示波器。正常启动不需要电脑下载。
2. 将信号源通过 BNC-SMA 连接所选 ADC 输入，共地。选择 HiZ 显示负载；可用 50 kHz、1 Vpp、0 V 偏置连续正弦开始，确认实际输入范围安全后打开输出。
3. 在界面选择已接信号的 CH1/CH2 与触发源，执行自动设置，观察波形、Vpp/RMS/频率；调节时基与垂直档位。
4. 依次演示 AUTO、NORMAL、单次。冻结后改变界面通道、游标或测量页，检查记录 ID 与原采样率保持；再恢复运行。
5. 在时域测量页演示占空比、正负脉宽和 10–90% 边沿时间。正弦或采样点不足时，部分测量会显示无效。边沿测量的精度及 PVT 范围尚待独立验证。
6. 冻结一条记录，进入 FFT，切换通道、Hann/矩形窗和去均值，手动更新快照。对比时域原记录率与频谱坐标。
7. 演示 RAM 波形暂存、改变实时采集率、再回放旧记录。回放应继续标记旧记录的原率；恢复 live 后原采集状态正常。
8. 插入 FAT32 TF 卡，在“记录→TF 存储”保存波形；在“参数管理→TF 存储”保存参数。返回采集页后断电，再 QSPI 上电，手动载入这两份文件。确认文件留存，RAM 槽清空。
9. 结束后关闭发生器输出。

仓库不提供一键擦写 Flash 的入口。使用开发期 JTAG 和信号源控制脚本前，需调整工具路径及设备配置；日常使用按以上步骤操作即可。
