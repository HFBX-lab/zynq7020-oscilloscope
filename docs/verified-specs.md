# 已验证范围与限制

本仓库对应 2026-10-29 完成实板验证的持久存储与 QSPI 自启动版本，应用 SHA256 为 `6917E229BE48D990EB7255ADA4E5BDDD052CEBF4B6E97BABD105C69C4B9C5A4C`，PL ABI 为 7，工程校准 profile 为 `2b474854`。完整固定产物 SHA 见 `release/SHA256SUMS.json`。

## 功能验证

双通道 10 bit / 50 MSa/s，4096 个双通道 32 bit 打包字；100 ns/div 至 500 ms/div 的 21 档时基。RAW 50M 和 CIC3 6.25M/625k/62.5k/6.25k/625 Sa/s；记录率由记录元数据绑定。独立硬触发、约20%预触发、AUTO/NORMAL/单次、游标与自动设置；Vpp、RMS、频率、占空比、正负脉宽与边沿测量。4096 点 FFT 是单记录快照，不是连续流式频谱仪。

本版 TF FAT32 的 14 次正式事务与 12 次导出、波形/参数逐字节重读、不同原率回放、DDR/RAM/FFT/校准身份保护和错误拒绝通过；实屏操作与真正断电后的 SCW/SCP 留存通过。波形格式为 SCWv2，兼容旧 v1 名义单位；参数格式 SCP1。TF 参数需手动恢复，RAM 两槽断电清空。

本版 BOOT 的两次 16 MiB 全片回读一致，与镜像前缀和其后原字节完全匹配；普通 QSPI 断电启动实屏通过。QSPI 冷启动后的只读检查确认 BOOT_MODE=1、DDR 正常、PL 自行配置、50M/ABI7、实际应用入口64KiB和6917 ELF一致，校准身份及系数正确。12.4779 秒 ID965→1042、epoch12保持；整个约20.319秒只读会话21条视频诊断正常，无 DMA 错误。

## 工程校准与幅频点

工程校准以专业信号源设定值为参考，未使用独立参考示波器或精密电压表，结果不具备计量溯源性。下表来自双路实板测量；持久存储版本保持相同校准 profile 与 PL。

| 项目 | IN1 | IN2 |
|---|---:|---:|
| 独立 DC 验证最大误差（相对源设定） | 4.533 mV | 6.594 mV |
| 50 kHz、1 Vpp 基波 | 1.000918 Vpp | 1.002275 Vpp |
| 5 MHz、1 Vpp 基波 | 1.019112 Vpp | 1.007149 Vpp |
| 5 MHz / 50 kHz 基波幅度比 | +0.156 dB | +0.042 dB |
| 0.2 Vpp / 50 kHz 余差 | +2.03%～+2.13% | +5.19%～+5.26% |
| 4 Vpp 正弦拟合 DC 余差 | −26.24～−24.32 mV | −22.46～−20.95 mV |

5 MHz 使用 RAW 50 MSa/s、1 Vpp、0 V 偏置；结果适用于该接线与信号源条件下的工程幅频点，尚未覆盖其他幅度、量程和温度。DC 系数训练范围为 ±2 V，独立验证点涵盖 ±1.5 V 和中间/零点，交流验证为 0.2～4 Vpp；±5 V 全量程精度尚待验证。

小信号幅度余差和幅度相关 DC 偏差见上表；纹波根因、外部 ADC 时钟脉宽/PVT 和长期温漂尚待进一步测量。采集采用定长记录，死区尚未量化，不支持连续 50 MSa/s 存盘；现有结果未覆盖全工况 5 MHz 模拟带宽。`measurement-summary.json` 提供可机读结果摘要，完整原始板测记录保存在本地。
